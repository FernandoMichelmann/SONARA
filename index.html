Perguntas frequentes

Como faço para criar uma conta?

Clique em “Cadastre-se”, informe seus dados e conclua o cadastro. Use o mesmo e-mail para entrar na plataforma.

Esqueci minha senha. Como recuperar?

Na tela de login, selecione “Esqueceu sua senha?”. Enviaremos um link de recuperação para o e-mail cadastrado.

O que é uma multitrack?

É uma música dividida em faixas individuais, como bateria, baixo, guitarras, teclas e vozes, para controlar cada instrumento durante a reprodução.

Posso ouvir instrumentos separadamente?

Quando a multitrack estiver disponível, abra a música e use os controles de reprodução e SOLO para escolher as faixas que deseja ouvir.

Como funciona o acesso vitalício?

Consulte a página “Assinatura” para ver as condições do plano. Se tiver dúvidas sobre disponibilidade ou aquisição, fale com nosso suporte antes de realizar qualquer pagamento.

Preciso de ajuda com minha conta ou meus arquivos?

Envie uma mensagem para sonaramultitracks@gmail.com, descrevendo o problema. Não envie sua senha.
